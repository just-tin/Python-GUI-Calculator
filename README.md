# GUI Calculator

**Submitted by:** Mark Justin T. Jover

## Description

GUI Calculator is a desktop calculator application built with Python and
Tkinter. It features a clean, Xiaomi-inspired interface with a black and
orange color scheme. The calculator supports basic arithmetic
operations, including addition, subtraction, multiplication, and
division. It also includes Clear (C), Delete (DEL), decimal input, an
equals button, and keyboard support. The application uses a fixed-size
window.
